# The Scattered Days 物語と構成

## 一行で

初雪まで七日。巣をスズメバチに皆殺しにされた最後の蜜蜂が、連れ去られた妹たちを追って山頂を目指す。

## 旧案をやめた理由

旧案(蜂の子が道場を巡って弾幕マスターを目指す)は、

- 動機がない(なぜ道場を巡るのか、巡らないと何が困るのかがない)
- 内容がない(道場主は「免状をあげよう」と言うだけで、誰も何も失わない)
- 明るい

ので、次の三つを最初に決めた。

| | |
|---|---|
| 動機 | 妹たち(幼虫と蛹)がスズメバチに肉団子にされて持ち去られた。取り返しに行く |
| 時限 | 雪虫が飛んだ。七日で初雪が降る。蜜蜂は寒いと飛べず、一匹では冬を越せない。つまりハチノコ自身の死はもう決まっている |
| 主題 | 冬を越せない者たちが、残りの日々をどう使うか。会う敵はみな、同じ冬に死ぬ |

タイトルの「Scattered Days」は「散っていく日々」として読む。明るさを抜くため「!」を外した。

## 題辞

> 冬蜂の死にどころなく歩きけり　村上鬼城

ゲームの最初(クリックを待つ画面)と、最後の一行に置く。冬まで生き残ってしまった蜂が、死に場所もなく歩いている句。ハチノコの話はこの句の前日譚になる。

## 書き方の決まり(前作の反省より)

- 主題を台詞で言わせない。行動と物で語る
- 説明は「今この人物が必要としている情報」だけ
- 時間と場所は地の文一行に圧縮する(「五日前。霧の沢。」)
- 説明台詞のあとに、黙る人物を置く(ハチノコの「……。」)
- 弾幕そのものに主題を持たせる(セミの陽炎=幻、最終戦で降りはじめる初雪)
- 一言の伏線にラベルを付けない(スズムシの「春になったら、ぼくの子は、ぼくでできてる」)

## 登場人物

- **ハチノコ**(主人公、ニホンミツバチの働き蜂): 秋の終わりに羽化した、巣でいちばん若い蜂。口数が少なく、引かない。妹たちが生きていないことに、たぶん最初から気づいている。それでも行く。
- **ミツ**(姉): 序章だけに出る。ハチノコに飛び方を教え、蜂球に加わって死ぬ。
- **ユキムシ**: 雪虫。飛びはじめてから七日で初雪が来る、冬の知らせ。成虫は一週間ほどで死ぬ。手のひらの熱でも弱るほど熱に弱い。最初のボスとして戦ったあと、距離を取ってついてくる(近づくと死ぬので)。毎日「あと○日」と数える役。ハチノコとは、寒さで死ぬ者と熱で死ぬ者の組み合わせ。
- **オオスズメバチ**: 巣を襲った群れの先頭にいた働き蜂。悪ではない。自分の妹たち(新しい女王)を冬に送り出すために狩りをした。ハチノコの鏡像。

## 構成(地図)

地図は左から右へ日付が進む。各地方は「雑魚3ステージ+ボス」。三日前まで、各日は上下二つの地方の分かれ道になっていて、どちらか一方を越えれば次の日へ進める。どちらの道でも同じ筋の進み方になるよう、同じ日のボスには同じ役割を持たせた。

| 日 | 場所 | ボス | 担う筋 |
|---|---|---|---|
| 八日前 | 巣 | (偵察蜂) | 序章。巣が襲われる。姉の針を拾う |
| 七日前 | 雪虫の野 | ユキムシ | 時限の提示。ハチノコの熱が武器になると知る(蜂球) |
| 六日前 | 風の尾根 / 糸の藪 | アキアカネ / ジョロウグモ | 「もう食われてる」という疑いを植える |
| 五日前 | 霧の沢 / 砂の崖 | カゲロウ / アリジゴク | 命の長さと使い道。ユキムシも死ぬと分かる |
| 四日前 | 日だまりの石垣 / 枯れ木 | セミ / カブト | 否認と受容。ユキムシが「知ってるんでしょ」と問う |
| 三日前 | 星の河原 / 月の草むら | ホタル / スズムシ | 諦めへの誘惑 / 食われて次の命になること |
| 二日前 | 山頂 | 門番、偵察蜂 | 敵もまた冬に死ぬ側だと知る |
| 前日 | スズメバチの巣の奥 | 育房、老女王 | 妹たちが食べられたことの確認 |
| 初雪 | 最奥の部屋 | オオスズメバチ | 決着と選択 |

### 各ボスの役

- **ユキムシ**: 「ボクの雪も抜けられないなら、山の上で死ぬだけ」という試し。負けると熱でへばる(敗北の立ち絵)。
- **アキアカネ**: 夏を山で過ごし、秋に里へ下りて卵を産む。みんな山を下りていく中、上るのはハチノコだけ。食うために襲ってくる。
- **ジョロウグモ**: 卵を産み終えた母。「肉団子にされた子が、まだ生きてると思う?」。最後に「あとは冬に任せる」と手放す。手放せないハチノコとの対比。
- **カゲロウ**: 今朝生まれ、日暮れに死ぬ。口がない(成虫は食べない)。「何のために?」「踊るため」。
- **アリジゴク**: 三年すり鉢の底で待った。戦いの途中で羽化する(弾幕の段の変わり目)。外に出たら冬だった。
- **セミ**: 十一月に一匹だけ鳴いている。「まだ夏だ、陽炎が立ってる」。陽炎と逃げ水の弾幕=否認。最後に「知ってたよ」。
- **カブト**: 夏を生き延びてしまった甲虫。「凍えて死ぬより、割られて死にたい」。負けて礼を言う。
- **ホタル**: 十一月にホタルはいない。姉の口調で「もういいんだよ、おいで」と誘う。戦いのあと、ユキムシに「さっきから誰と話してたの?」と聞かれる。幻かどうかは書かない。
- **スズムシ**: 雌に食べられるために鳴く雄。「春になったら、ぼくの子は、ぼくでできてる」。結末の伏線。
- **門番**: 「返せるものは、もう何もない」。
- **偵察蜂**: ハチノコの巣を見つけた本人。翅がぼろぼろ。秋の働き蜂は冬を越せない。「あの子たちだけは、冬を越すんだ」。
- **育房**: 世話係が「蜜蜂の子? みんな、ここにいるわ。この子たちが食べたの」。繭が破れて新しい蜂が這い出してくる(朱雀の再生の弾幕)。
- **老女王**: 春に一匹で巣の最初の部屋を作った。「おまえも、一匹か」。奥の最後の娘たちを守る。
- **オオスズメバチ**: ミツの蜂球で殺されかけた。「おまえの妹たちは、この子たちになった」。戦いの途中で初雪が降りはじめる。

## 結末

オオスズメバチを倒すと、繭が破れて新しい女王たちが這い出してくる。ハチノコの妹たちを食べて育った女王たち。ここで選ぶ。

- **刺す**: 女王たちを刺し殺す。その山のスズメバチは絶える。
  - 後日談「翌年の秋。その山で、スズメバチを見た者はいなかった。」
- **見送る**: 女王たちは雪の中へ這い出し、冬を越しに行く。
  - 後日談「翌年の春。山のどこかで、一匹の女王が、最初の部屋を作りはじめた。」(老女王の台詞の繰り返し。来年の秋、またどこかの蜜蜂の巣が襲われる)

どちらを選んでも、そのあと雪の中を歩くハチノコの背中に、熱に弱いユキムシがとまる。「あったかいね、キミ。」で終わり、題辞の句を置く。

決着ではなく、選択とその代償で閉じる。どちらが正しいかは書かない。

## 物語に合わせた仕組み

- **蜜**: 旧「銭」。敵弾をかすめると溜まる。
- **部位破壊で弾が蜜に変わる**: 敵(部位・子機を含む)を倒すと、その敵が撃って画面に残っている弾がすべて蜜に変わって吸い寄せられる。今いちばん邪魔な弾を撃っている部位を狙う、という駆け引きが生まれる(「部位破壊の楽しさが現状無い」への答え)。
- **装備は物語の中で手に入る**: 最初は「散り針」と「羽ばたき」だけ。序章を越えると「姉の針」(巣の入り口で、スズメバチの死骸に刺さったまま残っていた針を抜く)、ユキムシを越えると「蜂球」(自分の熱が武器になると知る)。蜂球は、姉たちがスズメバチを蒸し殺した技。
- **地図の日付**: 地図の左上に「初雪まで あと○日」を出す。越えた中でいちばん先の日を数える。ノードを選ぶと日付も出る。
- **最終戦の初雪**: オオスズメバチの体力が半分を切ると、画面の上から初雪が降りはじめる(当たり判定のある弾)。精密な避けと、ばらばらな雪が混ざる。
