# The Scattered Days! 世界

物語は持たない。文字も使わない(最初の画面の題辞だけは置く)。世界は、色と形と動きだけで感じさせる。

## 題辞

> 冬蜂の死にどころなく歩きけり　村上鬼城

ゲームの最初、クリックを待つ画面にだけ置く(`ScenePreTitle`)。

## 世界

**草むらの一年を、一匹の蜂の目の高さから見る。**

地図の左から右へ、季節が一巡りする。巣を出て、冬の野から始まり、春の風、梅雨の霧、夏の日ざし、夏の夜、秋の月を抜けて、晩秋のスズメバチの巣で終わる。最後の戦いの途中で初雪が降りはじめ、一年は冬へ戻る。

各ステージの敵は、その季節その場所の主(ぬし)として、その季節のもので攻めてくる(霜・風・蜘蛛の巣・霧・砂・陽炎・甲虫・星・月・スズメバチ)。弾幕の題材そのものが、世界を語る。

## 世界を感じさせる場所

- **戦闘画面のキャンバスの中**: 地面の模様が、ごく薄く、ゆっくり下へ流れる。自機が前へ飛び続けていることを、体で感じさせる(`src/World/Ground.ts`)。地の色も場所ごとにほんのわずかに違う。
- **キャンバスの外**: 空の色、日や月の光、漂うもの(`css/scenery.css`)。
- **地図**: 地の色が左から右へ、季節に合わせて移ろう。ノードには文字の代わりにその場所の絵柄を描く。まだ行けない場所の絵柄は伏せる(`css/map.css`)。
  - 塊(同じ景色のノードが辺でつながったまとまり)の上下には、その場所を特徴づける小物を散らす。冬なら雪虫・雪の結晶・つらら、梅雨なら葦・カゲロウ・水の輪、晩秋ならスズメバチの巣・スズメバチ・紅葉など(`src/World/Prop.ts`, `src/Map/MapProps.ts`)。まだどのノードにも行けない塊の小物は伏せておき、たどり着いたときに初めて見える。

## 主人公

プレイヤーは蜂になる。外から説明しない。

- 戦闘画面では、上から見た自分(蜂)の姿で飛ぶ。翅は速すぎて形が見えず、扇のようにぶれて震える。止まっている間はあたりを見回し、動くとその向きへ体を向ける(`src/Game/Actor/Player.ts`)。
- 地図の上では、自分(蜂)が選んだノードへ飛んでいき、その上にとまる(`src/Map/MapBee.ts`)。
- 立ち絵は言葉を添えずに見せるだけ。最初のステージで一度だけ自分の姿を見せる。雪虫とは無言で向かい合い、倒すと熱にへばった顔を見せる。

## 決まり

- 文字で世界を語らない。台詞・地の文・ノードの名前を画面に出さない(題辞と、操作に必要なメニューや数字は除く)。
- 地図のCanvasの1行目(ノードの名前)は、編集用の覚え書きとしてだけ使う。
- キャンバスの中の景色は、弾と見間違えない形にする。点や小さな丸は使わず、大きな形の線だけを、ごく薄く描く(見た目と当たり判定を乖離させない)。
- キャンバスの外の色は base.css の4色と黒だけを混ぜて作る。
